# 簡易マシン語モニタ for Excel

## 概要

Excelで制作した、マシン語プログラムを入力する際の、簡易モニタです。<br>

８バイト単位で入力します。<br>

主に、シャープポケコン（SC61860系）等のプログラムを入力するために作成したものです。<br>

入力したデータは、Intel HEX形式に変換されます。<br>

これを、最終的に実機等へ読み込みます。

## 対応バージョン

Excel 2007以降

## 入力方法

Excel内に、`内を入力`・`内を変更`・`内をファイルへコピペ`が記載されています。<br>
この中の、`入力箇所`・`変更箇所`を入力します。<br>

初めに、`開始アドレス`を指定します。<br>

あとは、`入力欄`へ、８バイト毎にマシン語データを入力します。<br>

入力後、右へ`チェックサム`が表示されます。<br>
入力元に記載されているチェックサムと比較し、差異があればマシン語データを訂正してください。<br>

なお、`メモリマップ`は参考用であり、入力・変更する必要はありません。

全て入力したら、`黄色の箇所`をコピーして、別途`テキストファイル`へ貼り付けてください。<br>

余分な行（空白行等）があれば、削除してください。<br>

テキストファイルは、`Intel HEX形式（.hex）`で保存します。<br>

テキストファイルを保存後、Intel HEX形式から`バイナリ形式`へ変換します。<br>
変換するには、`hex2bin`を使用します。<br>

（コマンド例）<br>
　hex2bin hoge.hex<br>

実行すると、`バイナリ形式（.bin）`へ変換されます。<br>

これを、CMTで読み込むために、`音声データ形式`へ変換します。<br>
変換するには、`bin2wav`を使用します。<br>

（コマンド例）<br>
bin2wav -p 1251 hoge.bin<br>

実行すると、`音声データ形式（.wav）`へ変換されます。<br>

変換した音声データファイルを、`CMT`から読み込みます。<br>

## その他

Excelファイルの入力例として、ポケコンマシン語入門に掲載の、PC-1251用ゲーム『スクランブル』（PISIOX氏作）から一部記載しました。<br>

メモリマップと、入力欄の先頭箇所のみ入っています。<br>

プログラムは、権利上記載しておりません。<br>
